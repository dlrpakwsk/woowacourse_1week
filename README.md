# java-calculator-precourse


기능 목록

1. [ ] 빈 문자열 입력 시 0을 반환한다.
2. [ ] 쉼표(,) 또는 콜론(:)을 기본 구분자로 인식해 합계를 계산한다.
3. [ ] 음수 또는 숫자가 아닌 값이 들어오면 IllegalArgumentException을 발생시킨다.
4. [ ] Console API를 통해 입력을 받고 결과를 출력한다.
5. [ ] 입력 문자열에서 숫자를 추출하는 로직을 분리하여 메서드 단위로 구성한다.
6. [ ] main() 메서드에서 프로그램 실행 흐름을 관리한다.
7. [ ] 예외 발생 시 아무 출력도 하지 않는다.
8. [ ] 문자열에 \\n이 포함된 경우에도 정상적으로 작동한다.
9. [ ] 이스케이프 문자 형태의 개행(\n, \r\n)도 인식한다.
