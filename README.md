# java-calculator-precourse


구현할 기능 목록

1. [ ] 빈 문자열 입력 시 0을 반환한다.
2. [ ] 쉼표(,) 또는 콜론(:)을 기본 구분자로 인식해 합계를 계산한다.
3. [ ] 커스텀 구분자 지정 기능을 추가한다. (예: //;\n1;2;3 → 6)
4. [ ] 음수 또는 숫자가 아닌 값이 들어오면 IllegalArgumentException을 발생시킨다.
5. [ ] Console API를 통해 입력을 받고 결과를 출력한다.
6. [ ] 입력 문자열에서 숫자를 추출하는 로직을 분리하여 메서드 단위로 구성한다.
7. [ ] main() 메서드에서 프로그램 실행 흐름을 관리한다.
